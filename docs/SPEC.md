## 0. ภาพรวม

**Pitch:** Ash ถือลูกซองยืนเฝ้าประตูปราสาทของ Lord Arthur คอยเก็บทอง เรียกทหาร และร่ายเวทจากหน้ากระดาษ Necronomicon เพื่อยันฝูง Deadite 50 คลื่นไม่ให้แตะหนังสือ
ส่วนที่ดีกว่าต้นฉบับมีสามอย่าง: ยูนิตแต่ละแบบมีบทบาทต่างกันชัดเจน, มีด่านบอสทุก 10 ด่านที่หลบท่าได้จริง, และความยากไม่ดิ่งชันตอนท้ายเพราะกลับไปเล่นด่านเก่าเพื่อฟาร์มทองได้

| หัวข้อ | ค่า |
|---|---|
| มุมมอง | 2D ด้านข้าง สนามรบเลนเดียว เลื่อนกล้องตาม Ash [ยืนยัน] |
| ผู้เล่น | 1 คน ออฟไลน์ |
| ความยาว | คลื่นละ 2–4 นาที แคมเปญ 50 คลื่นราว 3–4 ชั่วโมง (ต้นฉบับ 2–3 ชั่วโมง [ยืนยัน]) |
| แพลตฟอร์ม | เบราว์เซอร์บนคอมและมือถือ จอแนวนอน เสิร์ฟในบ้านผ่าน `vite --host` |
| สไตล์ภาพ | การ์ตูน 2D สีสด ตัวหัวโต เส้นขอบหนา วาดเป็นเวกเตอร์ด้วยโค้ดแล้วรวมเป็น texture atlas (รายละเอียดใน ART_BIBLE เฟส 6) |
| ภาษา | ไทยเป็นหลัก สลับอังกฤษได้ |

**Anti-goals (สิ่งที่เกมนี้จะไม่ทำ)**
- ไม่ใช้ภาพ เสียง หรือเสียงพากย์จากเกมหรือจากหนังต้นฉบับ
- ไม่ deploy สาธารณะ ไม่มีออนไลน์ ไม่มีซื้อของในเกม ไม่มีกาชา
- ไม่ทำ 3D และไม่ทำหลายเลน
- ไม่เพิ่มของใหม่ก่อนเฟส 5 (เฟส 4 ต้องเหมือนต้นฉบับก่อน)

## 1. Core loop

### 1.1 ภายในหนึ่งคลื่น (ราว 2–4 นาที)
1. **หน้าเตรียมคลื่น**: ดูศัตรูที่จะมา [ยืนยัน] แล้วเลือกยูนิตที่จะพาไป (สูงสุด 8 ช่อง [เดา]) และสกิล 2 อัน [ยืนยัน]
2. **การต่อสู้**: ศัตรูเกิดที่ขอบขวาแล้วเดินซ้ายเข้าหาปราสาท ผู้เล่นทำสี่อย่าง:
   - **เดิน** Ash ซ้าย-ขวา ซึ่งยิงลูกซองและฟันเองอัตโนมัติ [ยืนยัน]
   - **เรียกทหาร** ด้วยเหล็กที่โรงตีเหล็กผลิตให้ทีละนิด [ยืนยัน]
   - **ร่ายเวท** ด้วยมานา [ใหม่] และคูลดาวน์
   - **เก็บทอง** ที่ศัตรูทำหล่น โดยต้องเดินไปเหยียบเอง ซึ่งเสี่ยงโดนตี [ยืนยัน]
3. **จบคลื่น**
   - ชนะเมื่อฆ่าศัตรูหมดทุกตัวตามตารางเกิด
   - แพ้เมื่อ Ash ตาย หรือ HP ของ Necronomicon เหลือ 0 [ยืนยัน]

### 1.2 ระหว่างคลื่น
หน้าสรุปผล → ร้านอัปเกรด (ใช้ทอง) → เลือกด่าน (ด่านถัดไป หรือด่านที่เคยผ่านแล้วเพื่อฟาร์มทอง) → หน้าเตรียมคลื่น

### 1.3 ภาพรวมทั้งเกม
- 50 คลื่นบนสนามรบเดียวกัน [ยืนยัน] แบ่งเป็น 5 บท บทละ 10 คลื่น
- แต่ละบทเปลี่ยนแค่ช่วงเวลาและอากาศของฉาก เช่น พลบค่ำ หมอก ฝน คืนไฟไหม้ และคืนพระจันทร์เลือด [เดา]
- ชนะคลื่น 50 แล้วปลดล็อกโหมด Endless [ยืนยัน]

### 1.4 ถ้าแพ้
- ได้เก็บทองที่เก็บมาแล้วในคลื่นนั้น 50% [เดา]
- กด "ลองใหม่" หรือ "ไปอัปเกรด" ได้ทันที

## 2. การควบคุม

ทุกปุ่มทำได้ทั้งคีย์บอร์ด/เมาส์และจอสัมผัส ไม่มีฟังก์ชันไหนที่ต้องใช้คีย์บอร์ดเท่านั้น

| การกระทำ | คีย์บอร์ด / เมาส์ | จอสัมผัส (แนวนอน) |
|---|---|---|
| เดิน Ash | A/D หรือ ←/→ (กดค้าง) | กดค้างครึ่งจอซ้ายหรือขวาในโซนกลางจอ คือนอกแถบปุ่ม [ยืนยัน: แตะครึ่งจอ] |
| เรียกทหารช่อง 1–8 | ปุ่ม 1–8 หรือคลิกไอคอน | แตะไอคอนที่แถบล่าง |
| ร่ายเวทช่อง 1–2 (ช่อง 3 เป็นของใหม่) | Q / E / R แล้วคลิกจุดบนสนาม | แตะปุ่มเวท แล้วแตะจุดบนสนาม |
| ร่ายเวทแบบเล็งอัตโนมัติ | กดปุ่มเวทซ้ำสองครั้ง | แตะปุ่มเวทสองครั้งติดกัน |
| ยกเลิกการเล็ง | คลิกขวา หรือ Esc | แตะปุ่ม × (การแตะปุ่มเวทเดิมซ้ำจะเป็นการร่ายแบบเล็งอัตโนมัติ) |
| หลบกลิ้ง [ใหม่ เฟส 5] | Space | ปุ่มหลบ หรือปัดขึ้น |
| หยุดเกม | P หรือ Esc (ตอนไม่ได้เล็งอะไรอยู่) | ปุ่ม ⏸ มุมขวาบน |
| เร่งเกม ×2 [ใหม่] | F | ปุ่ม ⏩ |

**กติกาการเล็งเวท**
- เวทแบบพื้นที่จะแสดงวงพรีวิวตามเมาส์หรือนิ้ว
- เล็งอัตโนมัติจะเลือกจุดที่ศัตรูหนาแน่นที่สุดในจอ
- เวทแบบเส้นตรงยิงไปทางที่ Ash หันอยู่ ไม่ต้องเล็ง

**ทิศที่ Ash หัน**
- ตอนเดิน หันตามทิศที่เดิน
- ตอนยืนนิ่ง หันหาศัตรูตัวที่ใกล้ที่สุด

**ข้อกำหนดของจอสัมผัส**
- เป้าแตะต้องใหญ่อย่างน้อย 56 px บนจอตรรกะ
- เผื่อขอบ safe-area สำหรับรอยบาก
- multi-touch: เดินค้างไว้พร้อมกับแตะเรียกทหารหรือร่ายเวทได้
- จอแนวตั้งจะขึ้นหน้า "หมุนจอ"

| ปราสาท + กำแพง | 160–340 | นักธนูบนกำแพงและเครื่องยิงหินอยู่ตรงนี้ [ยืนยัน] |

### 3.2 ทรัพยากร

| ทรัพยากร | ได้มาจาก | ใช้ทำอะไร | อายุ |
|---|---|---|---|
| **ทอง** [ยืนยัน] | เหรียญที่ศัตรูทำหล่น (Ash ต้องเดินไปเก็บ ระยะดูด 40 px อัปได้), โบนัสจบคลื่น `20 + 5×คลื่น` | อัปเกรดทุกอย่างระหว่างคลื่น | ถาวร เก็บในเซฟ |
| **เหล็ก** [ยืนยัน] | โรงตีเหล็กผลิต 4/วินาที เริ่มคลื่นมี 30 คลังจุสูงสุด 200 (อัปได้ทั้งคู่) | เรียกทหารและฮีโร่ | หมดเมื่อจบคลื่น |
| **มานา** [ใหม่] | ฟื้น 2/วินาที สูงสุด 100 ลูกแก้วมานาจากศัตรู +10 (ดรอป 4%) | ร่ายเวท | หมดเมื่อจบคลื่น เริ่มคลื่นเต็ม |

- เหรียญที่ตกอยู่จะหายไปใน 15 วินาที ถ้ายังไม่ได้เก็บตอนจบคลื่น จะได้ 50% [เดา: ต้นฉบับบังคับเดินเก็บ แต่ตอนจบคลื่นไม่รู้ว่าเกิดอะไรขึ้น]
- ค่าทองของศัตรูแต่ละตัว = `threat × 0.5` ปัดขึ้น (threat ดูข้อ 5)

### 3.3 เรียกทหาร
- แถบล่างจอมี 8 ช่องตามที่เลือกไว้ แต่ละช่องมีราคาเหล็กและคูลดาวน์ของตัวเอง [ยืนยัน: ใช้เหล็ก]
- ยูนิตเกิดที่บันได (x=360) แล้วเดินขวาไปจนเจอศัตรู [ยืนยัน] ถ้าไม่เจอ จะไปหยุดรอที่ x=2300
- **การจัดแถว [ใหม่]** แก้ปัญหาของต้นฉบับที่ทุกตัวต่อกันเป็นกำแพงแถวเดียวจนแต่ละแบบต่างกันน้อย [ยืนยัน]:
  - ยูนิตระยะประชิดหยุดเมื่อชนศัตรูตัวแรก
  - ยูนิตหอกตีจากแถวสองได้
  - ยูนิตระยะไกลหยุดห่างแนวหน้าเท่ากับระยะยิงของตัวเอง
- ฮีโร่อยู่ในสนามได้ชนิดละ 1 ตัว แต่ฮีโร่ต่างชนิดอยู่พร้อมกันได้ [ยืนยัน] และราคาแพงกว่าทหารปกติ [ยืนยัน]
- ยูนิตบนสนามพร้อมกันได้สูงสุด 40 ตัว (เพื่อประสิทธิภาพ) ฮีโร่ไม่นับรวม [เดา]

### 3.4 เวท
- ก่อนเริ่มคลื่นเลือก 2 อัน [ยืนยัน] ช่องที่ 3 ปลดล็อกในเฟส 5 [ใหม่]
- แต่ละเวทใช้มานาและมีคูลดาวน์ [ใหม่: ต้นฉบับน่าจะใช้แค่คูลดาวน์ [เดา]]
- รายชื่อเวทอยู่ในหัวข้อ 4.3 (ของต้นฉบับ) และ 6.2 (ของใหม่)

### 3.5 "เลเวล" (ขอให้ยืนยัน: ผมตีความเอง [เดา])
- ใน SPEC นี้ "เลเวล" หมายถึงสองอย่าง:
  1. ความคืบหน้าของด่าน: 1–50 แล้วต่อด้วย Endless
  2. ระดับอัปเกรดของแต่ละอย่าง
- **ไม่มี** EXP หรือการเลเวลอัปของ Ash ระหว่างคลื่น เพราะต้นฉบับไม่มี [เดา]
- แต่ละด่านได้ดาว 0–3 ดวง [ใหม่]:
  - 1 ดาว = ชนะ
  - 2 ดาว = HP หนังสือเหลือ 75% ขึ้นไป
  - 3 ดาว = HP หนังสือไม่ลดเลย
  - ดาวไม่ปลดล็อกอะไร เป็นแค่เป้าส่วนตัว

### 3.6 อัปเกรด (ใช้ทอง ระหว่างคลื่น) [ยืนยัน: ทองใช้อัปเกรดยูนิต Ash อาวุธ สกิล และปราสาท]

ค่าเริ่มต้นของราคาคือ `base × 1.6^ระดับปัจจุบัน` [เดา] ตารางนี้แสดงเฉพาะหมวด ตัวเลขจริงอยู่ใน `data/upgrades.json`

|---|---|---|
| Ash | HP [ยืนยัน], ดาเมจฟัน [ยืนยัน], ดาเมจลูกซอง, อัตรายิง, ความเร็วเดิน, ระยะดูดทอง | 10 |
| กองทัพ | แต่ละยูนิต: HP และดาเมจ +15% ต่อระดับ [ยืนยัน: อัปเกรดยูนิตได้] | 5 |

### 3.7 สิ่งป้องกันของปราสาท (ปลดล็อกและอัปด้วยทอง)
- **นักธนูบนกำแพง**: ระดับ 1–5 = 1–5 คน ยิงศัตรูในระยะ x ≤ 900 ทุก 1.6 วินาที ดาเมจ 6
- **เครื่องยิงหิน**: ทุก 8 วินาที ยิงไปที่จุดที่ศัตรูหนาแน่นที่สุดในระยะ x ≤ 1400 ดาเมจพื้นที่ 40 รัศมี 90 ระดับที่สูงขึ้นลดคูลดาวน์
- **หลุม** [เดา ทั้งกลไก]:
  - เป็นประตูกลที่หน้าบันได
  - เมื่อมีศัตรูเดินดินยืนบนหลุม 3 ตัวขึ้นไป หลุมจะเปิดและทุกตัวบนนั้นตกลงไปตาย ใช้ไม่ได้กับบอส
  - คูลดาวน์ 30 วินาที อัปแล้วลดเหลือ 14 วินาที
  - ศัตรูที่โดนผลักถอยหลังจนตกลงไปตอนหลุมเปิดอยู่ก็ตายเช่นกัน
- **โรงตีเหล็ก**: ระดับ 1–5 = เหล็ก 4 / 5 / 6.5 / 8 / 10 ต่อวินาที

### 3.9 เซฟ
- เก็บใน `localStorage` key `aodd.save` เป็น JSON ที่มี `schemaVersion` และฟังก์ชัน migrate ทีละเวอร์ชัน
- **เซฟอัตโนมัติ** ตอนจบคลื่น (ทั้งแพ้และชนะ), หลังซื้ออัปเกรด และหลังเปลี่ยน Settings
- **ไม่เซฟกลางคลื่น** ถ้ารีโหลดหน้าระหว่างคลื่น คลื่นนั้นจะเริ่มใหม่
- **กันเซฟเสีย**:
  - ก่อนเขียนทับ คัดลอกเซฟเดิมไปเก็บที่ `aodd.save.bak`
  - ถ้า JSON อ่านไม่ได้หรือ schema ผิด ให้โหลดจาก .bak แล้วแจ้งผู้เล่น
- ใน Settings มีปุ่ม Export/Import เซฟเป็นไฟล์ `.json` (ไว้ย้ายจากคอมไปมือถือ) และปุ่มลบเซฟที่ต้องกดยืนยันสองครั้ง
- ข้อมูลในเซฟ:
  - ด่านที่ผ่านแล้ว พร้อมดาว
  - ทอง
  - ระดับอัปเกรดทุกอย่าง
  - ยูนิต เวท และฮีโร่ที่ปลดล็อกแล้ว
  - ชุดยูนิตและเวทที่เลือกล่าสุด
  - เรลิกที่มีและที่ใส่อยู่
  - สถิติ Endless
  - Settings

### 3.10 ฟาร์มทอง (แก้ปัญหาที่ต้นฉบับโดนติว่า "ไม่มีทางฟาร์มทอง" [ยืนยัน])

- โบนัสชนะครั้งแรกเท่ากับ ×2 ของโบนัสจบคลื่น

### 5.1 คลื่นศัตรู (ด่าน)
ทุกด่านอยู่ใน `data/levels.json`

**ด่าน 1–10, 45, 50 ตั้งค่าเองทีละด่าน** เขียนเป็นรายการกลุ่ม:
`{ enemy, count, interval, startAt }`

**ด่านที่เหลือสร้างจากสูตร** (`data/wave_formula.json`):
- งบความยากต่อด่าน `B(n) = 30 + 14n + 0.35n²` [เดา] ตัวอย่าง: ด่าน 1 ≈ 44, ด่าน 25 ≈ 599, ด่าน 50 ≈ 1605
- ซื้อศัตรูจากรายชื่อที่ปลดล็อกแล้วตามค่า threat โดยถ่วงน้ำหนักให้ศัตรูใหม่โผล่บ่อยในด่านแรกที่มันโผล่
- แบ่งศัตรูเป็น 3–6 ระลอก แต่ละระลอกห่างกัน 15–25 วินาที
- บนสนามมีศัตรูพร้อมกันได้สูงสุด 60 ตัว ถ้าเกินจะรอคิวเกิด

**สูตรเดียวกันใช้กับโหมด Endless** ต่อจากคลื่น 50:
- งบเพิ่มขึ้น 6% ต่อคลื่น
- ทุก 10 คลื่นเจอบอสที่สุ่มมาจากบอสที่เคยชนะแล้ว
- เก็บสถิติคลื่นสูงสุดที่ไปถึง

## 8. ข้อกำหนดประสิทธิภาพ (จากบรีฟ)

- **ตรรกะเกมใช้ fixed timestep 60 ครั้งต่อวินาที** (dt = 1/60 วินาที)
  - ทุกระบบเดินตามจังหวะนี้: การเคลื่อนที่ คูลดาวน์ AI การเกิดศัตรู และการผลิตเหล็ก/มานา
  - ทุกค่าใน data ใช้หน่วยต่อวินาที **ห้ามผูกความเร็วหรือคูลดาวน์กับจำนวนเฟรม**
- **ตอนวาดให้ interpolate** ระหว่างสถานะของ tick ก่อนหน้ากับ tick ปัจจุบัน (alpha = เวลาที่เหลือสะสม / dt)
  - ลื่นที่ 120fps บนจอ 120Hz และเล่นได้ปกติที่ 60fps
  - เฟรมที่ช้าเกินจะไล่ tick ได้สูงสุด 5 tick ต่อเฟรม กันอาการ spiral
- **โหมด ×2** = รัน 2 tick ต่อช่วง dt ไม่ได้เปลี่ยน dt
- **เป้า fps ของ Phaser ตามอัตรารีเฟรชของจอ** ไม่ล็อก 60 ส่วน Settings "จำกัด 60fps" จะลดเฉพาะอัตราการวาด ตรรกะยังเดิน 60 tick ต่อวินาทีเหมือนเดิม
- **งบประมาณ** [เดา] ปรับในเฟส 7:

| รายการ | งบ |
|---|---|
| ศัตรูพร้อมกัน | ≤ 60 |
| ยูนิตฝั่งเรา | ≤ 40 (+ฮีโร่) |
| พาร์ติเคิล | ≤ 300 (สูง) / ≤ 120 (ต่ำ) |
| ตัวเลขดาเมจ | ≤ 40 |
| texture atlas | ≤ 3 ใบ |
| draw call | < 40 ต่อเฟรม |

- **เทคนิคที่ต้องใช้**:
  - texture atlas
  - object pooling สำหรับกระสุน เหรียญ พาร์ติเคิล ตัวเลขดาเมจ และตัวละคร
  - ไม่สร้าง object ใหม่ใน loop ที่วิ่งทุก tick
- **QA**: วัดเฟรมไทม์ (p50/p95/p99) ทั้งที่ 60 และ 120 แล้วรายงาน รวมถึงฉากที่หนักที่สุด (คลื่น 50 และ Endless คลื่น 70)
- ระบบเดียวกันทำให้ทดสอบได้ด้วย `window.advanceTime(ms)` ซึ่งเดินตรรกะแบบกำหนดผลได้ (deterministic) และ `window.render_game_to_text()` สำหรับ QA

## 9. ข้อมูลเกมใน `data/` (เพิ่มของใหม่ได้โดยไม่แก้โค้ด)

| ไฟล์ | เนื้อหา |
|---|---|
| `data/units.json` | ทหารและฮีโร่ฝั่งเรา: ค่าพลัง ราคา คูลดาวน์ ปลดล็อก รายการ behavior, ลูกน้องที่มาด้วย, ออร่า |
| `data/enemies.json` | ศัตรู: ค่าพลัง threat เกราะ behavior คลื่นที่เริ่มโผล่ ดรอป |
| `data/bosses.json` | บอส: HP เกณฑ์เปลี่ยนเฟส ลำดับท่าของแต่ละเฟส (อ้าง id ท่า + พารามิเตอร์) ดรอป |
| `data/spells.json` | เวท: มานา CD การเล็ง ผล ต้นสกิล 3 ระดับ (A/B) |
| `data/upgrades.json` | อัปเกรด: หมวด ระดับสูงสุด ราคาฐาน ตัวคูณ ผลต่อระดับ |
| `data/levels.json` | ด่าน 1–50: ด่านที่ตั้งค่าเอง และด่านที่อ้างสูตร |
| `data/wave_formula.json` | พารามิเตอร์สูตรคลื่น และค่าของ Endless |
| `data/relics.json` | เรลิก |
| `data/balance.json` | ค่ากลาง: ขนาดสนาม เหล็ก/มานาเริ่มต้น อัตราดรอป ทองตอนแพ้ งบประสิทธิภาพ |
| `data/i18n/th.json`, `en.json` | ข้อความทั้งหมด |

**กติกา data**
- ตรวจ schema ทุกไฟล์ตอน boot ถ้าผิดให้ขึ้นข้อความบอกว่าผิดที่ไฟล์ไหน ฟิลด์ไหน
- ตัวละครใหม่ประกอบจาก **behavior ที่มีอยู่แล้ว**:
  - เช่น `melee`, `ranged`, `flying`, `leap_once`, `siege_ignore_units`, `aura`, `healer`, `escort`
  - ใช้ behavior ที่มีอยู่ ไม่ต้องแก้โค้ด
  - ถ้าต้องการ behavior หรือท่าบอส **ชนิดใหม่จริงๆ** ต้องเขียนโค้ดเพิ่มใน `gameplay/` แล้วลงทะเบียน id
- ภาพของตัวละครอ้างด้วยชื่อ sprite key ถ้ายังไม่มีภาพจะใช้ placeholder
