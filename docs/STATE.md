### รอบนี้ทำแล้ว (ผู้ใช้ขอ 8 ข้อ + 5 ข้อค้าง)

1. **เสียง:** เปลี่ยนเป็นเสียงอัดจริง CC0/CC-BY 134 ไฟล์ (3.7 MB) ดูที่มาใน public/assets/audio/CREDITS.md
   - เสียง synth เดิมเหลือไว้เป็น fallback
   - เพลงยังเป็น procedural
2. **UI:** ธีม "สมุดบัญชีสงคราม" (กระดาษเวลลัม หนัง เหล็ก ตราครั่ง)
   - ฟอนต์ Taviraj, Chonburi, Pirata One (OFL)
   - ชุดภาพ UI เจนเองทั้งหมดใน public/assets/ui/kit
3. **ความคม:** renderScale คิดจากพิกเซลจริงที่จอแสดง (เดิมใช้แค่ devicePixelRatio จอ 1080p จึงยืดภาพ 720p) และเปิด mipmap
4. **Ash ไม่โกงแล้ว:** ปืน 11 ดาเมจ/1.5 วิ ทะลุ 1 ตัว ระยะ 280, ฟัน 10/0.8 วิ, HP 220, ความเร็ว 190
5. **ดรอปสองอย่าง:** ทอง (อัปเกรดในร้าน) และเงิน (= iron ในโค้ด ใช้เรียกทหารและอัปช่างตีเหล็ก)
   - เงินดรอป 0.6 ต่อ threat เก็บเองอัตโนมัติ แล้วบินไปที่แผงช่าง
   - เพิ่มเพดานคลังเงินของช่าง
6. **คลื่นมาต่อเนื่อง:** เคลียร์สนามหมดแล้วกลุ่มถัดไปมาใน 2.5 วิ เหลือศัตรู ≤3 ตัวมาใน 6 วิ (wave_formula.pacing) ช่วงห่าง sub-wave 10–16 วิ
7. **ความเร็วและตำแหน่ง:** ความเร็วต่างกันตามชนิด และสุ่มรายตัว ±7%
   - ยิงไกลและฮีลยืนหลังแนวประชิด 120 px
   - ถ้าไม่มีแนวประชิด ยืนหลัง Ash และไม่เกิน x 900
8. **บั๊กที่แก้:**
   - ปีกตัวบินหมุนทับหัว (บานพับผิดแกน) bake ใหม่แล้ว
   - เวฟค้างเพราะ catapult ยืนที่ประตู: ศัตรูต้องเดินเข้าสนาม 160 px และฝ่ายเราไล่ตามเลยแนว hold ได้
   - Malachar เรียกลูกน้องไม่จำกัด: ตอนนี้จำกัดไว้ 8 ตัว
9. **ข้อค้างเดิม:**
   - คำอธิบายเวทแต่ละระดับ (t1/t2/t3a/t3b) และแถวซื้อ spell tree ในร้าน
   - ภาพ bear_trap, holy_light, lance, coffin, pumpkin_head, poison_flask
   - ลดสีบทไฟไหม้/พระจันทร์เลือด
   - fx หายากโหลดหลังเริ่มเวฟ (เริ่มต้นโหลดแค่ 10 แผ่นเล็ก)
   - บอทเล่น 50 คลื่น 3 กลยุทธ์ (output/lead/bot.mjs) แล้วปรับบอส ทุกค่ายังเป็นเดา:
     - Gravewright 1300, Mire 1700, Hollow 2700, Malachar 2800, Sheila 2000, Evil Ash 4200
     - ดาเมจบอส x0.8
   - ผลบอท army: ชนะ 48/50 คลื่น (แพ้บอส 20 กับ 50 บ้าง) ส่วน Ash เดี่ยวแพ้ตั้งแต่คลื่น 7

### รอบ 2026-11-18 ค่ำ (ผู้ใช้: เสียงห่วย, เกมง่ายเกิน, แมพสั้น)

  - เงิน 0.5 ต่อ threat

## ปัญหา / ข้อสังเกต
- **ยังไม่ได้วัดเฟรมไทม์บนมือถือหรือจอ 120 Hz จริง** headless Chrome วาดได้ ~165 fps เพราะไม่มี vsync เฟส 7 ต้องวัดบนเครื่องจริงผ่าน `npm run dev:lan`
- **ตัวจำกัด 60fps** ใช้ฟิลด์ภายในของ Phaser TimeStep (`_limitRate`) ถ้าวันหน้าอัป Phaser ต้องเช็กส่วนนี้ใหม่
- **ไม่ได้ทำ texture atlas จริงในเฟสนี้** placeholder ใช้ DynamicTexture แยกเป็นใบๆ ส่วน atlas จะทำในเฟส 6 ตอนวาดภาพจริง
- **Vite** ยังเป็น 6.x ตามเทมเพลต (ล่าสุด 8.x) ยังไม่อัปเพราะไม่มีความจำเป็น
- **skill ไม่ตามมาตอนย้ายโฟลเดอร์** ถ้าหาย ให้ติดตั้งใหม่ด้วย `npx skills add OpusGameLabs/game-creator -a claude-code`
- **คำแนะนำของ skill phaser ที่ไม่ใช้กับโปรเจกต์นี้**: "Play.fun safe zone", "ไม่มีหน้าเมนู", "ไม่มี HUD คะแนน" เป็นค่าเริ่มต้นของ skill สำหรับเกมแบบอื่น แต่บรีฟของเราต้องการเมนูและ HUD
