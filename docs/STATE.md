**ขั้นถัดไป (เรียงตามลำดับ)**
1. แก้ `slotinfo.mjs` แล้วดูแกนของช่องมือ เพื่อวางปืนกับเลื่อยของ Ash ให้ถูก
2. เขียน `tools/bake/src/defs/*.ts` ตัวแรก (Ash, นักดาบ, ชาวนา, โครงกระดูก) แล้วรัน job `sprite` ดู preview ปรับแสงและขนาด
3. เขียน ADR-0002 + `docs/ART_BIBLE.md` (ใช้ skill design-game) และแก้ SPEC: มุมกล้อง 20 องศา, 75 px ต่อหน่วย, ตัวละครสูงราว 165 px, แถบความลึกของเลน, HUD แบบต้นฉบับ
4. อบฉากหลังลานปราสาท (กำแพง คบเพลิง โรงตีเหล็ก) แบ่งชั้น parallax
5. เขียน renderer ฝั่งเกมใหม่ให้เล่นสไปรต์เฟรม (โหลด atlas ต่อคลื่น, เลือกเฟรมจาก animTime, เงา, แถบความลึก) แล้วปรับ HUD/เมนู/เอฟเฟกต์
6. เกมเพลย์: จังหวะง้างก่อนโจมตี (windup), อัปเกรดช่างตีเหล็กกลางด่าน (ต้นฉบับมีจริง ยืนยันจาก MobyGames), ราคายูนิตตามภาพต้นฉบับ (ชาวนา 5, นักดาบ 10, ทหารหอก 15, นักธนู 10), เนื้อหาเฟส 4–5
7. เสียง (Web Audio), บอทบาลานซ์ 50 ด่าน, รอบ improve-game สุดท้าย, ส่ง Artifact

## ปัญหา / ข้อสังเกต
- **ยังไม่ได้วัดเฟรมไทม์บนมือถือหรือจอ 120 Hz จริง** headless Chrome วาดได้ ~165 fps เพราะไม่มี vsync เฟส 7 ต้องวัดบนเครื่องจริงผ่าน `npm run dev:lan`
- **ตัวจำกัด 60fps** ใช้ฟิลด์ภายในของ Phaser TimeStep (`_limitRate`) ถ้าวันหน้าอัป Phaser ต้องเช็กส่วนนี้ใหม่
- **ไม่ได้ทำ texture atlas จริงในเฟสนี้** placeholder ใช้ DynamicTexture แยกเป็นใบๆ ส่วน atlas จะทำในเฟส 6 ตอนวาดภาพจริง
- **Vite** ยังเป็น 6.x ตามเทมเพลต (ล่าสุด 8.x) ยังไม่อัปเพราะไม่มีความจำเป็น
- **skill ไม่ตามมาตอนย้ายโฟลเดอร์** ถ้าหาย ให้ติดตั้งใหม่ด้วย `npx skills add OpusGameLabs/game-creator -a claude-code`
- **คำแนะนำของ skill phaser ที่ไม่ใช้กับโปรเจกต์นี้**: "Play.fun safe zone", "ไม่มีหน้าเมนู", "ไม่มี HUD คะแนน" เป็นค่าเริ่มต้นของ skill สำหรับเกมแบบอื่น แต่บรีฟของเราต้องการเมนูและ HUD
