## ค่าเริ่มต้นที่ยังไม่ได้ถาม (จะเขียนลง SPEC ให้ผู้ใช้แก้ได้)
- บังคับ Ash ตามต้นฉบับ: คีย์บอร์ด A/D หรือ ←/→ ส่วนจอสัมผัสใช้การแตะค้างครึ่งจอซ้ายหรือขวา (นอกโซนปุ่ม HUD) ยิงและฟันอัตโนมัติ
- เรียกทหารด้วยแถบปุ่มล่างจอ จ่ายเหล็ก มีคูลดาวน์ คีย์ลัด 1–9 เวทใช้คีย์ Q/W/E/R หรือปุ่มบนจอ
- เลือกสกิล 2 อันก่อนเริ่มแต่ละคลื่นตามต้นฉบับ (จำนวนช่องอาจเพิ่มได้ในส่วนอัปเกรด)

## ข้อกำหนดประสิทธิภาพ (จากบรีฟเพิ่มเติม จะเขียนลง SPEC และ ARCHITECTURE)
- ตรรกะเกมทั้งหมดใช้ fixed timestep 60 ครั้งต่อวินาที แล้ว interpolate ตอนวาด ความเร็วและคูลดาวน์ต้องไม่ผูกกับจำนวนเฟรม
- เป้า fps ของ Phaser ตามอัตรารีเฟรชของจอ ไม่ล็อกที่ 60 ต้องลื่นที่ 120fps บนจอ 120Hz และเล่นปกติที่ 60fps
- ใช้ texture atlas, object pooling และจำกัดจำนวนพาร์ติเคิล
- Settings มีตัวเลือก: จำกัด 60fps / ไม่จำกัด
- QA ต้องวัดเฟรมไทม์ทั้งที่ 60 และ 120 แล้วรายงาน

## ปัญหา / ข้อสังเกต
- บรีฟใช้ `docs/SPEC.md` ส่วน skill make-game ใช้ `docs/gameplan.md` จะให้ SPEC.md เป็นต้นฉบับ แล้วทำ gameplan.md เป็นไฟล์สั้นที่ชี้ไป SPEC จะได้ไม่มีสองเวอร์ชันขัดกัน
- skill make-game ให้ทำทีละฟีเจอร์ต่อ session แต่บรีฟเฟส 3 สั่งให้ subagent 4 ตัวทำขนานกัน **ยึดบรีฟ** โดยแบ่งเจ้าของตามโฟลเดอร์ และขอแก้ contracts.ts ผ่านหัวหน้าเท่านั้น
- ข้อมูลต้นฉบับเรื่องค่าสถานะ ศัตรูแต่ละตัว และผลของสกิลแต่ละอันมีน้อยมาก ตัวเลขส่วนใหญ่ใน SPEC จะติดป้าย [เดา]
- skill ที่ติดตั้งไว้ (`.claude/skills/`) ถูกคัดลอกมาจากโฟลเดอร์ session เดิมตอนย้ายโฟลเดอร์ ถ้าหายให้ติดตั้งใหม่ด้วย `npx skills add OpusGameLabs/game-creator -a claude-code`

- Phaser 4.2.1 เป็น `latest` บน npm แล้ว แต่บรีฟระบุ Phaser 3 (ล่าสุด 3.90.0) ผมยึด 3 ไว้ (ADR-0001) และถามผู้ใช้ไว้ใน SPEC §10 ข้อ 7
- `npm create @phaserjs/game@latest` อาจได้ Phaser 4 เป็นค่าเริ่มต้น ต้องเช็กตอนเฟส 2 แล้วปักเวอร์ชัน 3.x
