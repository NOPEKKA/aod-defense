# Audio credits

All sound effects in `sfx/` are trimmed, normalised, mono 16-bit WAV excerpts of the sources below, downloaded from OpenGameArt (https://opengameart.org). None come from the original game or the film. Each source page lists its author; where the pack author is not named here, see the page.
