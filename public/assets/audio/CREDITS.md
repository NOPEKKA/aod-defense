# Audio credits

None of these sounds come from the original game (Backflip's *Army of Darkness: Defense*) or from the *Army of Darkness* / *Evil Dead* films.

## Sound effects (`sfx/`)

138 one-shots, Ogg Opus, 48 kHz mono, 128 kbps (about 2.4 MB in all). Each file is an excerpt of one or more of the sources below. Some files are layered from several sources (for example the shotgun blasts are a designed Saiga-12 core, a Remington 870 room recording, a low-passed explosion for the sub boom and a 12-gauge slug shot for the crack). All files were trimmed, faded, peak-normalised (and lightly limited where layered), then encoded. The build tools and source downloads are not shipped (`output/sfx2-tools/`, `output/sfx2-src/`, gitignored). Pitch/volume variation and round-robin are applied at runtime in `src/audio/samples.ts`.
